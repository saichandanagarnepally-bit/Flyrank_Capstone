# AI Project Guidelines

## Project

FlyRank Frontend AI Internship

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js

## Coding Conventions

- Write clean and readable code.
- Use semantic HTML.
- Keep CSS organized.
- Use meaningful variable names.
- Explain changes before making major edits.

## Git

Use Conventional Commits for every commit.

## Goal

Learn frontend development with AI assistance while understanding the code.

## Best Practices

- Keep code modular and readable.
- Write meaningful commit messages.
- Test changes before committing.
- Prefer simple, maintainable solutions.

## Project Rules Learned

1. Always provide detailed prompts with clear requirements before asking AI to generate code.

2. Every form must include proper labels, validation, and accessibility features.

3. Review and verify AI-generated code before committing it to Git.

4. Keep HTML, CSS, and JavaScript in separate files for better maintainability.

5. Use Git branches to experiment with different AI prompting approaches without affecting the main branch.
