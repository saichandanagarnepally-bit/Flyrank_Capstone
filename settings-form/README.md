# Settings Form

A responsive settings page built with HTML, CSS, and JavaScript.

## Features

- Profile fields (name, email, timezone)
- Notification toggles
- Theme preference (light, dark, system)
- Privacy options
- Client-side validation
- Settings saved to `localStorage`

## Run locally

Open `index.html` in your browser, or serve the folder with a static server:

```bash
npx serve .
```

Then visit the URL shown in the terminal (usually `http://localhost:3000`).
